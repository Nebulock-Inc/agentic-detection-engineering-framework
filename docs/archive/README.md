# docs/archive

Superseded and development-only documents, kept for history. Nothing here is
current — it's the paper trail behind decisions that now live in `ISA.md` and
features that now live in the root `README.md`, `docs/quickstart.md`, and
`docs/cli-reference.md`. Retained pending a final keep-or-delete pass; not
part of the shipped, user-facing doc set.

**What's here and why it's archived:**

- **Dev-status snapshots** (`STATUS.md`, `HANDOFF.md`, `verification.md`) —
  the "what's real" status page, feature-branch handoff, and 31-fact
  verification trail from the v0.1.0 build. Point-in-time; the living sources
  are the README (what's shipped) and `ISA.md` (decisions/verification).
- **Framework essay** (`forge-framework-comparison.md`) — long-form FORGE-vs-
  others comparison, never linked from the public docs.
- **Decision records** (`decisions-000-*`, `decisions-008-*`) — meeting-derived
  design decisions, superseded by `ISA.md`'s `## Decisions`.

- **Meeting / brainstorming plans** (June–early July 2026):
  `2026-06-25-*`, `2026-06-26-*`, `2026-07-01-*`, `2026-07-07-*`, `2026-07-09-*`
  — the design conversations that shaped v1. Outcomes are in `ISA.md`.
- **Schema-storage specs** (`2026-07-14-schema-storage-design`,
  `2026-07-15-schema-storage-implementation*`) — the *rules-derived* schema
  model, replaced 2026-07-20 by the declaration-driven model
  (`docs/plans/2026-07-20-schema-declaration-design.md`).
- **"What's real" snapshots** (`existing-vs-roadmap`, `whats-real-vs-proposed`,
  `v0.1.0-current-state`, `command-summary-for-team`) — 2026-06-25 point-in-time
  inventories, replaced by `STATUS.md` (now also archived here) and,
  ultimately, the living root `README.md`.
- **Command explainers** (`cli-commands-roadmap`, `forge-commands-explained`,
  `detection-list-explained`, `detection-creation-skill`,
  `skills-and-agents-for-workflows`) — superseded by `CLAUDE.md` + the shipped
  plugin skills.
- **Session ephemera** (`2026-07-20-status-and-design-changes`,
  `2026-07-21-session-status`, `2026-07-21-next-steps`,
  `2026-07-21-handoff-full`, `schema-feature-progress`) — rolled into
  `HANDOFF.md` / `STATUS.md` (both now archived here too).
